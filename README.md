# PostgreSQL Projects

This repository documents my journey learning PostgreSQL through the Udemy course *The Complete SQL Bootcamp* by Jose Portilla.  

## Learning Goals
- Practice SQL fundamentals (SELECT, WHERE, ORDER BY, LIMIT)
- Explore GROUP BY, HAVING, and aggregation functions
- Work with JOINs and advanced SQL commands
- Create and manage databases, tables, and constraints
- Learn conditional expressions, views, and import/export
- Connect PostgreSQL with Python using psycopg2

## Progress Tracking
- Week 1: SQL Fundamentals — SELECT, WHERE, ORDER BY
- Week 2: GROUP BY and Aggregations
- Week 3: JOINs and Advanced SQL
- Week 4: Database Design and Constraints
- Week 5: Conditional Expressions, Views, Import/Export
- Week 6: Python Integration with PostgreSQL
